passage opens the original concept and its Lean encoding beside the PDF. The
source identifiers are also clickable in the PDF itself. The chapters are a
reading order, not new definitions or claims of equivalence between
formalizations. This submission has no concepts or proofs of its own.

\section{Graph classes and closure}

% lax begin Lax199508.GraphClasses
\textbf{Graph classes.} The sparsity lectures use families of finite simple
graphs on canonical vertex sets; see
\source{lax-199508}{Lax199508.GraphClasses}.
% lax end

% lax begin Lax871432.GraphClasses
\textbf{Isomorphism-closed graph classes.} A separate submission develops
class operations in an isomorphism-invariant setting; see
\source{lax-871432}{Lax871432.GraphClasses}.
% lax end

% lax begin Lax871432.ClosureProperties
\textbf{Closure properties.} This concept covers induced-subgraph, minor,
contraction, summand, and union closure. Induced-subgraph closure is the
hereditary-class property; see
\source{lax-871432}{Lax871432.ClosureProperties}.
% lax end

% lax begin Lax153141.GraphParameters
\textbf{Graph parameters.} A common signature and functional equivalence of
parameters appear in \source{lax-153141}{Lax153141.GraphParameters}.
% lax end

% lax begin Lax199508.NowhereDenseClasses

% lax end

% lax begin Lax199508.UniformQuasiWideness
\textbf{Uniform quasi-wideness.} The distance-independent-set viewpoint is
in \source{lax-199508}{Lax199508.UniformQuasiWideness}.
% lax end

% lax begin Lax710763.GraphClasses
\textbf{Weakly sparse classes.} Exclusion of a complete bipartite subgraph
is formalized in \source{lax-710763}{Lax710763.GraphClasses}.
% lax end

% lax begin Lax710763.MonadicDependence

appears in \source{lax-710763}{Lax710763.MonadicDependence}.
% lax end

% lax begin Lax68.Planar

\source{lax-68}{Lax68.Planar}.
% lax end

% lax begin Lax68.Outerplanar
\textbf{Outerplanar graphs.} The corresponding drawing-based concept is
\source{lax-68}{Lax68.Outerplanar}.
% lax end

% lax begin Lax68.SeriesParallel

composition is treated in \source{lax-68}{Lax68.SeriesParallel}.
