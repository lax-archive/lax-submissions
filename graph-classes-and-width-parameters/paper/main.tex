\section{Graph classes and closure}

This opening section collects the vocabulary for talking about families of
graphs and how they behave under standard operations.

% lax begin Lax199508.GraphClasses
\textbf{Graph classes.} The sparsity lectures represent a class by its finite
simple graphs on canonical vertex sets, giving a common starting point for
the later sparsity notions; see
\source{lax-199508}{Lax199508.GraphClasses}.
% lax end

% lax begin Lax871432.GraphClasses
\textbf{Isomorphism-closed graph classes.} Another treatment makes closure
under isomorphism explicit and provides union and intersection operations;
see
\source{lax-871432}{Lax871432.GraphClasses}.
% lax end

% lax begin Lax871432.ClosureProperties
\textbf{Closure properties.} This concept groups closure under induced
subgraphs, minors, contractions, disjoint-union summands, and disjoint union.
In particular, induced-subgraph closure is the usual hereditary property;
see
\source{lax-871432}{Lax871432.ClosureProperties}.
% lax end

% lax begin Lax153141.GraphParameters
\textbf{Graph parameters.} This concept gives a shared signature for
natural-number graph parameters and records when two parameters bound one
another up to functions; see
\source{lax-153141}{Lax153141.GraphParameters}.
% lax end

\section{Sparse graph classes}

The examples below move from familiar planar families to containment and
width notions, then to the order parameters and class properties used to
describe nowhere-dense graphs.

\subsection{Planar graph classes}

The order follows the inclusions where they apply: paths and stars are
subclasses of trees; trees, ladders, and maximal outerplanar graphs are
outerplanar; and outerplanar graphs, series-parallel graphs, and
triangulations are planar. The triangle family is included among the maximal
outerplanar graphs.

% lax begin Lax68.Paths
\textbf{Paths.} These are the finite path graphs, the simplest connected
examples in the list; every path is a tree. See
\source{lax-68}{Lax68.Paths}.
% lax end

% lax begin Lax68.Stars
\textbf{Stars.} These trees have one centre joined to all other vertices;
their leaves have no edges between them. See
\source{lax-68}{Lax68.Stars}.
% lax end

% lax begin Lax68.Trees
\textbf{Trees.} A tree is connected and acyclic, so both paths and stars
form subclasses of the tree family. See \source{lax-68}{Lax68.Trees}.
% lax end

% lax begin Lax68.Ladders
\textbf{Ladders.} A ladder is a two-row grid, with two paths joined by
corresponding rungs. See \source{lax-68}{Lax68.Ladders}.
% lax end

% lax begin Lax68.GridsAndWalls
\textbf{Grids and walls.} These standard planar families also illustrate
the role of large grid-like structures in planar graph theory. See
\source{lax-68}{Lax68.GridsAndWalls}.
% lax end

% lax begin Lax68.Triangles
\textbf{Triangles.} The concept singles out the three-vertex complete graph,
a basic maximal outerplanar example. See
\source{lax-68}{Lax68.Triangles}.
% lax end

% lax begin Lax68.MaximalOuterplanar
\textbf{Maximal outerplanar graphs.} These are outerplanar graphs to which no
further edge can be added while preserving outerplanarity. See
\source{lax-68}{Lax68.MaximalOuterplanar}.
% lax end

% lax begin Lax68.Outerplanar
\textbf{Outerplanar graphs.} Every vertex can be placed on the boundary of a
crossing-free drawing; this family is contained in the planar graphs. See
\source{lax-68}{Lax68.Outerplanar}.
% lax end

% lax begin Lax68.SeriesParallel
\textbf{Series-parallel graphs.} These graphs are built from a terminal edge
by series and parallel composition; the concept makes the terminal and
support conditions explicit. See
\source{lax-68}{Lax68.SeriesParallel}.
% lax end

% lax begin Lax68.Triangulations
\textbf{Triangulations.} A triangulation is a maximal planar supergraph on
the same vertices, so it describes a way to complete a planar graph. See
\source{lax-68}{Lax68.Triangulations}.
% lax end

% lax begin Lax68.Planar
\textbf{Planar graphs.} The concept uses a crossing-free straight-line
drawing in the plane as its certificate. See
\source{lax-68}{Lax68.Planar}.
% lax end

\subsection{Minors and treewidth}

Minor containment compares graphs by deletions and contractions; treewidth
measures how closely a graph can be assembled from small overlapping bags.
Grids and walls are standard planar examples that connect these viewpoints.

% lax begin Lax68.GraphMinors
\textbf{Graph minors.} The branch-set formulation packages vertex deletion,
edge deletion, and contraction into one containment relation. See
\source{lax-68}{Lax68.GraphMinors}.
% lax end

% lax begin Lax68.GraphTopologicalMinors
\textbf{Topological minors.} Here edges of the smaller graph are represented
by internally disjoint paths, rather than arbitrary connected branch sets.
See \source{lax-68}{Lax68.GraphTopologicalMinors}.
% lax end

% lax begin Lax762056.InducedMinors
\textbf{Induced minors.} This variant preserves both edges and non-edges
between the retained branch sets, making it stricter than ordinary minor
containment. See \source{lax-762056}{Lax762056.InducedMinors}.
% lax end

% lax begin Lax68.GridsAndWalls
\textbf{Grids and walls.} The concept defines rectangular grids and their
brick-wall subgraphs, recurring examples in planar structure theorems. See
\source{lax-68}{Lax68.GridsAndWalls}.
% lax end

% lax begin Lax762056.Grid
\textbf{Excluded induced grid minors.} This class condition forbids an
induced minor isomorphic to a square grid of the specified size. See
\source{lax-762056}{Lax762056.Grid}.
% lax end

% lax begin Lax228581.Treewidth
\textbf{Treewidth.} Tree decompositions measure the largest bag needed to
cover vertices and edges while keeping each vertex's bags connected. See
\source{lax-228581}{Lax228581.Treewidth}.
% lax end

% lax begin Lax228581.TwinWidth
\textbf{Twin-width.} Its partition-sequence measure applies to both sparse
and dense graph classes, so it complements treewidth here. See
\source{lax-228581}{Lax228581.TwinWidth}.
% lax end

\subsection{Admissibility and nowhere-dense classes}

These notions describe sparsity through bounded-radius paths, reachability
orders, and the exclusion of dense shallow minors.

% lax begin Lax199508.Admissibility
\textbf{Admissibility.} For an ordering, this parameter counts how many
short paths from one vertex can reach earlier vertices while meeting only at
their start. See \source{lax-199508}{Lax199508.Admissibility}.
% lax end

% lax begin Lax199508.ColoringNumbers
\textbf{Generalized coloring numbers.} Weak and strong reachability count
vertices accessible along short paths under a linear ordering; the coloring
numbers minimize the worst such count over orderings. See
\source{lax-199508}{Lax199508.ColoringNumbers}.
% lax end

% lax begin Lax199508.UniformQuasiWideness
\textbf{Uniform quasi-wideness.} Large vertex sets contain large
distance-separated subsets after removing a bounded-size separator, uniformly
over the class. See
\source{lax-199508}{Lax199508.UniformQuasiWideness}.
% lax end

% lax begin Lax199508.ShallowMinorDensity
\textbf{Shallow-minor density.} This records edge density after bounded-depth
contractions, at each fixed radius. See
\source{lax-199508}{Lax199508.ShallowMinorDensity}.
% lax end

% lax begin Lax199508.ShallowTopologicalMinors
\textbf{Shallow topological minors.} This companion notion bounds the
subdivision depth of the paths representing edges. See
\source{lax-199508}{Lax199508.ShallowTopologicalMinors}.
% lax end

% lax begin Lax199508.NowhereDenseClasses
\textbf{Nowhere-dense graph classes.} At every fixed depth, some clique is
excluded as a shallow minor of every member. See
\source{lax-199508}{Lax199508.NowhereDenseClasses}.
% lax end

% lax begin Lax199508.NeighborhoodComplexity
\textbf{Almost-linear neighborhood complexity.} This bounds the number of
distinct neighborhood traces on any vertex set by a near-linear function of
its size. See \source{lax-199508}{Lax199508.NeighborhoodComplexity}.
% lax end

\section{Dense graph classes}

These concepts describe graph classes that can contain dense graphs, together
with parameters used to organize them. The inclusion order is explicit for
cographs and bounded cliquewidth; the other notions provide separate ways to
control dense structure.

\subsection{Cographs and width classes}

% lax begin Lax214022.Cographs
\textbf{Cographs.} These are exactly the graphs of twin-width zero in the
chosen formulation, a restricted dense-capable family. See
\source{lax-214022}{Lax214022.Cographs}.
% lax end

% lax begin Lax271696.CliqueExpr
\textbf{Cliquewidth.} A $k$-expression builds a graph using $k$ labels;
bounded cliquewidth therefore organizes classes by the number of labels
needed. Cographs have cliquewidth at most two. See
\source{lax-271696}{Lax271696.CliqueExpr}.
% lax end

% lax begin Lax9.MergeWidth
\textbf{Merge-width.} This parameter measures merge sequences using the
radius-$r$ neighborhoods in their partially resolved graphs. See
\source{lax-9}{Lax9.MergeWidth}.
% lax end

% lax begin Lax228581.TwinWidth
\textbf{Twin-width.} The partition-sequence parameter counts red neighbors
created as vertex parts are merged, and applies to both sparse and dense
families. See \source{lax-228581}{Lax228581.TwinWidth}.
% lax end

% lax begin Lax153141.MixedMinorNumber
\textbf{Mixed minor number.} This parameter looks for fully mixed blocks in
ordered adjacency matrices, giving another measure comparable to twin-width.
See \source{lax-153141}{Lax153141.MixedMinorNumber}.
% lax end

\subsection{Controlled density and class properties}

% lax begin Lax710763.GraphClasses
\textbf{Weakly sparse classes.} Such a class excludes one fixed complete
bipartite graph as a subgraph; this still allows edge counts that grow
superlinearly. See \source{lax-710763}{Lax710763.GraphClasses}.
% lax end

% lax begin Lax710763.MonadicDependence
\textbf{Monadically dependent classes.} The concept characterizes classes
that cannot produce every graph by first-order transductions with vertex
colorings. See \source{lax-710763}{Lax710763.MonadicDependence}.
% lax end

% lax begin Lax9.ChiBoundedness
\textbf{$\chi$-boundedness.} A class is controlled when chromatic number is
bounded as a function of clique number, even if the class itself is dense.
See \source{lax-9}{Lax9.ChiBoundedness}.
% lax end

% lax begin Lax9.NeighborhoodComplexity
\textbf{Linear neighborhood complexity.} This counts distinct neighborhood
traces and asks for a linear bound in the size of the tested vertex set. See
\source{lax-9}{Lax9.NeighborhoodComplexity}.
% lax end

% lax begin Lax379983.FeedbackVertexNumber
\textbf{Feedback vertex number.} This measures how many vertices must be
removed to leave a forest; see
\source{lax-379983}{Lax379983.FeedbackVertexNumber}.
% lax end

% lax begin Lax379983.FeedbackEdgeNumber
\textbf{Feedback edge number.} Its edge-deletion counterpart removes edges
until the remaining graph is acyclic; see
\source{lax-379983}{Lax379983.FeedbackEdgeNumber}.
% lax end
